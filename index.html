§ 01

三步锻造 / how it works

无需本地环境、无需证书折腾。全部在 GitHub 的 runner 上完成。

  1. 01

    连接 GitHub

    一键 OAuth 授权，FORGE 自动创建 forge-app/<name> 仓库，注入 workflow、secrets 与图标资源。

    oauth · create-repo · write-workflow
  2. 02

    配置应用

    在工坊里设置名称、图标、包名、窗口、权限、离线缓存与更新通道，实时预览多端外观。

    visual-config · live-preview

    触发构建

    推送 forge.yml，Action 在矩阵 runner 上并行锻造五端产物，签名后发布到 Release，并经 CDN 加速分发。

    matrix-build · sign · release · cdn

§ 05

Action 流水线 / pipeline

由 forge.yml 编排的一次完整构建。

01checkout拉取仓库 + 镜像加速
02setupnode / rust / jdk / sdk
03webview注入配置与图标
04matrix5 端并行锻造
05sign签名 / 公证
06release发布 + CDN 加速
.github/workflows/forge.yml 
name: FORGE build
on: { push: { branches: [main] } }
jobs:
  forge:
    strategy:
      matrix:
        target: [ios, android, windows, macos, linux]
    steps:
      - uses: actions/checkout@v4
      - uses: forge-app/setup@v2            # 注入镜像加速
      - run: forge build --target ${{ matrix.target }}
      - uses: forge-app/sign@v2             # 签名 / 公证
      - uses: forge-app/release@v2           # 发布 + CDN 分发
§ 06

常见问题 / faq

需要自备服务器吗？+

不需要。全部构建在 GitHub Actions 提供的免费 runner 上完成，FORGE 只负责配置与编排。私有仓库每月有 2000 分钟免费额度。

iOS 签名怎么解决？+

将 Apple Developer 证书与描述文件作为 GitHub Secrets 注入，FORGE 在云端完成 codesign 并可直传 TestFlight。也支持免签名的 PWA 与企业签名方案。

国内拉取 GitHub 太慢怎么办？+

FORGE 在 setup 步骤自动启用镜像加速，对 clone / raw / api 透明代理；产物发布后通过 jsDelivr CDN 与自建镜像分发，下载提速 5–20 倍。

支持离线运行吗？+

支持。开启「离线缓存」后，FORGE 会注入 Service Worker 与资源预缓存，断网时仍可启动应用外壳。
